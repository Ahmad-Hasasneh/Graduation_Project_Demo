# Intelligent Traffic Light 🚦

## Overview
AI-powered traffic light system using computer vision to adapt to real-time traffic conditions. 
Integrates YOLOv8 for vehicle detection with tracking algorithms to count cars and dynamically 
adjust signal timing, reducing congestion and optimizing traffic flow.

## Demo
🎥 Watch the project demo here: [https://drive.google.com/file/d/1df7M-D6slysFKwhYlrVuCXmTsOK7U3SB/view?usp=sharing]

## Features
- Real-time car detection using YOLOv8
- Vehicle tracking and counting
- Dynamic traffic light timing based on density
- Designed to improve efficiency and reduce congestion

## Technologies Used
- Python
- YOLOv8
- OpenCV
- Machine Learning & Computer Vision
